📊 생산 및 물류 수불일보
원료·부재료 │ 전일 + 입고 − 투입 = 현재고 (재고는 정수, 소수점 잔량은 투입에 포함)
반제품 │ 전일 + 생산 − 투입 = 현재고 (kg)
완제품 │ 전일 + 생산 − 출고 = 현재고
부자재 │ 전일 + 입고 − 투입(레시피) = 현재고
※ 쿠팡 납품 상품은 출고일 당일 생산(주문생산). 원료는 선입선출. 반제품 = 원료 투입량 × 공정 수율(당일 전량 투입). "기초" 표시 원료는 기록 시작(7/23) 전 보유 재고 이월분. LOT 번호를 누르면 이력과 연계(순·역추적)가 표시됩니다.
